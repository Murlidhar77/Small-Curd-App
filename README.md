# React Profile Management App

A simple profile management application built with React. I created this project as a hands-on practice exercise to strengthen my understanding of React fundamentals and form handling.

The main goal was to build something on my own and apply the concepts I've been learning instead of just following tutorials.

## Features

- **Create Profile:** Add a new profile with name, email, phone number, and profile image.
- **Display Profiles:** Dynamically render profile cards using React's `map()`.
- **Delete Profile:** Remove a profile from the list.
- **Form Validation:** Validate required fields before submitting the form.
- **Conditional Rendering:** Switch between the profile form and the profile cards.

## Concepts Practiced

- React Components
- Props and Component Communication
- State Management with `useState`
- State Lifting
- Conditional Rendering
- Dynamic Rendering using `map()`
- React Hook Form
- Form Validation
- Handling Form Submissions
- Passing State Update Functions Between Components

## Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- React Hook Form
- Vite

## What I Learned

While building this project, I got more comfortable with how React components communicate with each other.

I particularly focused on lifting state to the parent component and passing functions through props to update that state from child components.

I also practised handling forms using React Hook Form, including registering inputs, handling submissions, displaying validation errors, and resetting the form.

The project helped me understand how different React concepts work together in a practical application.

## Running Locally

Clone the repository:

```bash
git https://github.com/Murlidhar77/Small-Curd-App.git
```

Navigate into the project:

```bash
cd react-hook--form-2
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
